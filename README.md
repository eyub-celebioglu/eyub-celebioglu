### Eyub Celebioglu

M2 student in AI, Vision & Robotics at Université de Lorraine (Nancy, France).

I work on reinforcement learning, motion planning and computer vision for autonomous robots. Last year I did my M1 research project on autonomous navigation in uncertain environments: RRT planning, a shortcut variant called RRTSC, and a DQN agent that follows the planned paths.

I would like to become a researcher, and I am looking for a six-month research internship in 2027.

Most of what's here is coursework or things I built to understand how they work, often from scratch:

- [XOR-NeuralNetwork-CPP](https://github.com/Eyub4k/XOR-NeuralNetwork-CPP): an MLP and backprop in C++ with OpenMP, no ML library
- [snake-DQN](https://github.com/Eyub4k/snake-DQN): deep Q-learning on Snake
- [anime_pictures_generator](https://github.com/Eyub4k/anime_pictures_generator): a DCGAN that generates anime faces
- [3Dengine](https://github.com/Eyub4k/3Dengine) / [Minecraft-cpp](https://github.com/Eyub4k/Minecraft-cpp): an OpenGL engine with physics, then a voxel engine
- [MaidChan](https://github.com/Eyub4k/MaidChan): a voice assistant running local LLMs with Ollama

I mostly write Python (PyTorch) and C++. Outside of that: anime, cats, and a small Unity game with friends.
